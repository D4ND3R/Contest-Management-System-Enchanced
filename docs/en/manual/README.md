# CMS manual

*Español: [Manual de CMS](../../es/manual/README.md)*

A step-by-step manual for organizing programming contests with CMS: from
installing the server to publishing the results. If it is your first time,
read it in order; if you are looking for something specific, use the
table.

| Chapter | What it is for |
|---|---|
| [1. Concepts](01-concepts.md) | what each thing is: contests, tasks, datasets, judges, tokens… and the life cycle of a contest |
| [2. Installation](02-installation.md) | installing, reading the installer's errors, clean install, uninstalling |
| [3. First access and admin accounts](03-first-steps.md) | logging in to the administration, your team's accounts, recovering a password |
| [4. Contests](04-contests.md) | creating and configuring a contest field by field, groups and schedules |
| [5. Tasks](05-tasks.md) | creating and configuring tasks, datasets, testcases, testing them |
| [6. Task types and score types](06-task-and-score-types.md) | Batch, graders, checkers, OutputOnly, Communication…; subtasks |
| [7. Importing](07-importing.md) | importing contests and tasks (italy_yaml, Polygon, TPS, zip) |
| [8. Users, teams and participations](08-users-and-teams.md) | registering contestants with a CSV, participations, extra time |
| [9. During the contest](09-during-the-contest.md) | checklist, submissions, reevaluating, questions, announcements, incidents |
| [10. The contestant site](10-contestant-site.md) | what the contestants see and a sheet to print |
| [11. The public scoreboard](11-scoreboard.md) | visibility, secret link, freezing, logo and flags |
| [12. After the contest](12-after-the-contest.md) | exporting results, final backup, analysis mode |
| [13. Maintenance and `cmsctl` reference](13-maintenance.md) | services, logs, backups, upgrades, all the `cmsctl` commands |
| [14. Troubleshooting](14-troubleshooting.md) | `cmsctl doctor` and the frequent problems |

**Shortcut to get started:** [short installation guide](../getting-started.md) →
[ch. 3](03-first-steps.md) → [ch. 4](04-contests.md) →
[ch. 7](07-importing.md) or [ch. 5](05-tasks.md) →
[ch. 8](08-users-and-teams.md) → [ch. 9](09-during-the-contest.md).

The technical reference documentation (configuration, API, package
format, Docker…) is in [the general index](../README.md).
