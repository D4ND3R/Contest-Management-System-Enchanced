# Manual de CMS

*English: [CMS manual](../../en/manual/README.md)*

Manual paso a paso para organizar concursos de programación con CMS: desde
instalar el servidor hasta publicar los resultados. Si es tu primera vez,
léelo en orden; si buscas algo puntual, usa la tabla.

| Capítulo | Para qué |
|---|---|
| [1. Conceptos](01-conceptos.md) | qué es cada cosa: concursos, problemas, datasets, jueces, tokens… y el ciclo de vida de un concurso |
| [2. Instalación](02-instalacion.md) | instalar, leer los errores del instalador, instalación limpia, desinstalar |
| [3. Primer acceso](03-primer-acceso.md) | entrar a la administración, cuentas de tu equipo, recuperar una contraseña |
| [4. Concursos](04-concursos.md) | crear y configurar un concurso campo por campo, grupos y horarios |
| [5. Problemas](05-problemas.md) | crear y configurar problemas, datasets, casos de prueba, probarlos |
| [6. Tipos de problema y de puntaje](06-tipos-de-problema-y-puntaje.md) | Batch, graders, checkers, OutputOnly, Communication…; subtareas |
| [7. Importar](07-importar.md) | importar concursos y problemas (italy_yaml, Polygon, TPS, zip) |
| [8. Usuarios y equipos](08-usuarios-y-equipos.md) | registrar concursantes con un CSV, participaciones, tiempo extra |
| [9. Durante el concurso](09-durante-el-concurso.md) | lista de control, envíos, reevaluar, preguntas, anuncios, incidentes |
| [10. Sitio del concursante](10-sitio-del-concursante.md) | lo que ven los concursantes y una hoja para imprimir |
| [11. Scoreboard](11-scoreboard.md) | visibilidad, enlace secreto, congelamiento, logo y banderas |
| [12. Después del concurso](12-despues-del-concurso.md) | exportar resultados, respaldo final, modo análisis |
| [13. Mantenimiento](13-mantenimiento.md) | servicios, registros, respaldos, actualizaciones, todos los comandos `cmsctl` |
| [14. Solución de problemas](14-solucion-de-problemas.md) | `cmsctl doctor` y los problemas frecuentes |

**Atajo para empezar:** [guía corta de instalación](../primeros-pasos.md) →
[cap. 3](03-primer-acceso.md) → [cap. 4](04-concursos.md) →
[cap. 7](07-importar.md) o [cap. 5](05-problemas.md) →
[cap. 8](08-usuarios-y-equipos.md) → [cap. 9](09-durante-el-concurso.md).

La documentación técnica de referencia (configuración, API, formato de
paquete, Docker…) está en [el índice general](../README.md).
